# 🚗 Car Landing Page

A modern and responsive automotive landing page designed to present cars in a clean, premium, and engaging interface.

This project was originally built as a frontend practice project and has been redesigned with a more modern UI, responsive layouts, smooth interactions, and an animated Light/Dark theme.

## ✨ Features

* 🚘 Modern automotive landing page
* 🎨 Clean and premium UI design
* 🌙 Animated Light / Dark mode
* 💾 Theme preference saved with `localStorage`
* 📱 Fully responsive design
* 👉 Mobile-friendly horizontal scrolling
* 🚗 Explore cars by body type
* 🔎 Car search section
* 🖼️ Interactive car showcase cards
* ✨ Smooth hover effects and transitions
* 📐 Responsive desktop, tablet, and mobile layouts
* ⚡ Lightweight HTML, CSS, and JavaScript implementation

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* CSS Flexbox
* CSS Grid
* Responsive Web Design
* CSS Variables
* LocalStorage
* CSS Transitions & Animations

## 🎨 Main Sections

### 🏠 Hero Section

The hero section introduces the automotive experience with a strong visual presentation and clear call-to-action elements.

### 🚘 Explore by Type

Users can explore vehicles according to their body style.

Example categories include:

* Sedan
* SUV
* Coupe
* Truck

On desktop, the categories are displayed in a structured layout.

On mobile devices, the cards can be horizontally swiped for a smoother browsing experience.

### 🔎 Find Your Car

A dedicated search interface allows users to interact with the car discovery section.

The layout is designed to remain usable across different screen sizes.

### 🚗 Car Showcase

Vehicle cards present individual cars with a clean visual layout and interactive hover effects.

The design focuses on:

* Vehicle image
* Vehicle name
* Vehicle information
* Visual hierarchy
* Smooth interactions

## 🌙 Light & Dark Mode

The website includes an animated theme toggle.

Users can switch between:

**Light Mode**

and

**Dark Mode**

The selected theme is stored using browser `localStorage`.

This means the user's theme preference remains available after refreshing the page.

The theme is implemented using CSS variables, making it easy to maintain and extend.

## 📱 Responsive Design

The website is designed for:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

The layout automatically adapts to different screen sizes using responsive CSS.

### Mobile Experience

On smaller screens:

* Navigation adapts to the available space
* Car cards resize naturally
* Explore categories become horizontally scrollable
* Content spacing is optimized
* Images remain responsive
* No unnecessary horizontal page overflow

## ✨ UI & Interaction

The interface includes subtle animations and micro-interactions to make the website feel more polished.

Examples include:

* Card hover effects
* Theme toggle animation
* Smooth transitions
* Button interactions
* Image transitions
* Horizontal mobile scrolling

The animations are intentionally lightweight so that the interface remains responsive.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ohin03/car-landing-page.git
```

### 2. Open the project

```bash
cd car-landing-page
```

### 3. Run the website

This is a frontend project, so no backend setup is required.

Simply open:

```text
index.html
```

in your browser.

### Using VS Code

You can also use **Live Server**:

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right-click inside the HTML file.
4. Select **Open with Live Server**.
